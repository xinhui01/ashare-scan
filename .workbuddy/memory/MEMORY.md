## Git 跟踪引用沙箱限制（重要）
- 本沙箱环境下 git 自身的引用写盘被拦截：`git update-ref` 返回成功但不生效；`git push`/`git fetch` 也**不会刷新** `origin/main` 远程跟踪引用。
- 表现：`git status` 持续误报 `ahead N`（如 ahead 293 / ahead 1），但 `git ls-remote origin main` 查到的远程真值始终正确（推送其实已成功）。
- **验证同步是否成功唯一可靠方式**：`git ls-remote origin main`（直接问 GitHub）。
- 修正本地显示假 "ahead N"：直接编辑 `.git/packed-refs`，把 `refs/remotes/origin/main` 那行改成 `git ls-remote` 返回的 SHA；`git update-ref` 在此环境无效。
- 直接改 packed-refs 文件（Edit/Write 工具）可持久生效、rev-parse 能正确读取；不要依赖 update-ref/push/fetch 去刷新该引用。

## 策略复盘教训（预判次日用）
- 当 涨停总数 / 晋级率 / 市场情绪 三者同步骤升 = 情绪 regime 切换为**进攻**，不要停留在"轮动日=防守"旧框架；应预案"情绪爆量则转攻、跟随当日新主线"。
- 主线有惯性但也轮动：预判次日时，主线以"**当日**最强行业/题材"为准，不要机械沿用前一日主线（案例：0803夜按电网设备→0804实际切元件/芯片半导体，一夜切换）。
- 超短纪律：持仓若掉出强度池 TOP10 且不在主线内 → 优先换主线而非死扛；开盘核 5日线，破即走。
- 反包池被系统标"谨慎/回避"时，即便大环境火热也按规则不做（案例：中岩大地 0803 连板 → 0804 被砸成反包）。

## 退潮期纪律（0805~0808 验证，0808 框架修正）
- 情绪/涨停/晋级率三者连续回落（85/102/22.9% → 63/84/12.9% → 53/74/9.5%）= 退潮 regime
- **⚠️ 核心修正（用户 0808 纠正）**：成交量和涨停个数不会骗人。74+ 涨停 + 万亿成交 = **活跃市场**，不是空仓理由。
  系统情绪 53/100 标"半仓"——应按半仓参与（3~5成），不该比系统本身更保守直接跳到空仓。
  退潮 ≠ 空仓；退潮 = 降仓位（5→3成）+ 收紧止损（破5日线即走）+ 只做最强标的 + 不做杂毛。
- **"指数涨+情绪跌"分歧信号**（0807: 上证+1.02% 但情绪53/涨停74/晋级率9.5%）= 大票撑指数题材退潮，但仍有74只涨停可做
- **主线一天可崩**：0806 计算机通信电子主线20只 → 0807 直接0只，追主线=追高被套
- 广和通闭环验证（0806→0807）：竞价条件三条全不满足 → 正确未入场；但这不等于"退潮期不做"，而是"条件不满足不做"
- **前排分析纠错（0808）**：0807 前排5只我判"全有硬伤"是错的。豪尔赛主力+83.94+量比3.3x=爆量承接（强反包标的，不应因"反包池"标签否决）；
  联环药业主力-3.43=中性（不应判流出）；海南海药换手20%=活跃非风险。5只里只有中文在线(-74)、铜陵有色(-80)主力大幅流出该谨慎。
- **前排分析方法论**：不能套标签否决（"反包池"≠不做、"PE亏损"≠超短不做）；必须看 K 线形态 + 资金流 + 量比，逐只判断。
  主力净额 > -5 基本中性；量比 > 2 是活跃信号；反包标的要看爆量承接还是爆量出货（主力正负是关键）。
- **反包胜率与情绪强相关（0809 复盘 0803~0807 十笔反包实测）**：
  情绪 ≥ 85 → 反包胜率 60%（可做）；情绪 ≤ 63 → 反包胜率 17%（极差，只做评分最高+爆量承接的标的）。
  低情绪下唯一成功的是传智教育（评分100，全场最高）→ 高分票即使退潮也能反包。
  连续多天在反包池的票 = 持续阴跌（"反包池老赖"），不做。反包做不做不看星期几，看情绪绝对值。
- **已反包失败的票不做（0810 新增）**：恒银科技 08/06 反包涨停(主力+1.36亿)→08/07 暴跌-10%(主力-1.44亿撤退)→08/10 续跌-6%。
  反包涨停次日暴跌=反包已失败，不能做"二次反包"。判断标准：反包涨停后次日若跌>5%且主力净流出，视为反包失败，后续不再做。

## 预测验证体系（代码架构）
- `src/services/prediction_accuracy_service.py`：核心评估服务，T+1 OHLC 回填命中结果。
  三级命中口径：`hit_strict`（次日涨停且非一字）、`hit_loose`（开盘买收盘≥5%或涨停）、`hit_buyable`（非一字非停牌）。
  反包(wrap)走 hit_loose；保留涨停(cont)走 hit_strict。
  含 `classify_failure()` 失败归因（冲高回落/低开低走/弱势震荡/大跌跌停/其他）。
- `src/services/scoring/wrap.py`：反包评分，硬性条件≥2板连板→被打掉→反包缺口≤11%。
  含 `_count_historical_wrap` 近90日反包成功次数加分（3次+8/2次+5/1次+2）。
- `stock_store.py`：`limit_up_prediction_accuracy` 表存预测vs实际对比，`simulated_buy_trades` 表追踪模拟买入盈亏。
- `scripts/diag_accuracy.py`：直连SQLite查命中率（整体/按类别/按分数段/失败归因/每日趋势）。
- `scripts/backtest_lookback.py`：lookback参数回测，含写库拦截保护。
- `src/gui/tabs/predict.py`：GUI"命中对比"按钮展示。
- 快照JSON（`snapshots/latest_prediction.json`）只同步预测输入，**不记录命中结果**——命中验证由各机器本地独立计算。
