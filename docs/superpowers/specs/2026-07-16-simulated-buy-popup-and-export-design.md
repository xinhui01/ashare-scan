# 模拟买入弹窗与当日导出设计

## 目标

调整模拟买入页面的信息层级：主页面只展示当前加载预测日的模拟买入，全部历史记录和账户累计收益率分别通过按钮打开独立窗口。Excel 导出增加当前预测日的模拟买入工作表。

## 主页面

- 模拟买入表格只展示当前加载预测日自动选择的最多两只股票。
- 当前日已经产生 T+1 结果时显示交易日、买入价、卖出价、盈亏和状态；尚未产生结果时显示等待交易。
- 右侧保留选中记录的买入当日分时收益图。
- 顶部增加“历史模拟买入”和“收益率”两个按钮。
- 不再在主页面直接铺开全部历史记录，也不在主页面嵌入账户累计收益率图。

## 历史模拟买入弹窗

- 点击“历史模拟买入”打开独立窗口。
- 从模拟交易流水读取全部历史记录，按预测日倒序展示。
- 展示预测日、交易日、代码、名称、来源、预测分、买入价、卖出价、单笔盈亏、状态和入选依据。
- 使用现有命中/未命中行颜色。
- 弹窗只读，不修改历史记录。

## 收益率弹窗

- 点击“收益率”打开独立窗口。
- 读取全部模拟交易流水，复用现有每日等权、跨日复利算法。
- 上方显示总记录数、有效交易数、胜率、账户累计收益率和单笔平均收益率。
- 图表横轴为交易日期，纵轴为账户累计收益率，并显示 0% 基准线。
- 没有有效交易时显示“暂无已完成交易”。

## Excel 导出

- 现有候选、汇总和题材工作表保持不变。
- 新增“模拟买入”工作表。
- 仅导出当前加载预测日对应的模拟交易流水，不导出全部历史。
- 字段包含预测日、交易日、代码、名称、来源、预测分、买入价、卖出价、单笔盈亏、状态和入选依据。
- GUI 在调用导出服务前按当前预测日筛选流水，并将筛选结果作为参数传入；Excel 服务不直接访问数据库。
- 当前预测日没有流水时仍创建“模拟买入”工作表，只保留表头，确保导出结构稳定。

## 数据与异常处理

- 主页面通过 `self.result.trade_date` 或当前加载结果的交易日筛选流水。
- 若流水后台同步尚未完成，主页面先保存当前选出的快照并渲染；同步完成后再次刷新。
- 历史/收益率弹窗重复点击时复用并前置已有窗口，避免打开多个重复窗口。
- 窗口关闭后清理引用，允许下次重新创建。
- 数据库读取、图表空数据和 Excel 空当日记录均安全降级，不影响其他预测导出。

## 测试

- Excel 导出包含“模拟买入”工作表，且只写入调用方传入的当前日记录。
- 空记录仍产生只有表头的工作表。
- 主页面渲染按当前预测日筛选，不展示其他日期。
- 模拟买入页包含“历史模拟买入”和“收益率”按钮。
- 历史弹窗读取全部流水并倒序展示。
- 收益率弹窗调用全部历史流水和账户复利曲线计算。
- 现有分时选择、预测候选和 Excel 工作表回归测试保持通过。

## 非目标

- 不改变模拟买入选股、买卖时点和收益计算口径。
- 不导出全部历史模拟交易。
- 不在弹窗中增加编辑、删除或手工交易功能。
- 不改变其他候选工作表格式。
