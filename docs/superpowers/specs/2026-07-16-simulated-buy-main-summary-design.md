# 模拟买入主页面统计与布局修复设计

## 目标

修复上一版主页面调整造成的历史累计统计缺失，并按最新要求删除主页面右侧买入当日分时区域。

## 页面布局

- 顶部保留“历史模拟买入”和“收益率”按钮。
- 摘要区域显示两行：第一行是当前预测日统计，第二行是全部历史统计。
- 当前预测日模拟买入表格铺满剩余宽度。
- 删除主页面的“买入当日分时收益”标题、Figure、Canvas、选择事件和异步分时加载逻辑。

## 统计口径

- 当日行只统计当前加载预测日的流水：记录数、有效数、胜率、单笔平均收益和等待交易数。
- 历史行统计全部流水：总记录数、有效交易数、胜率、账户累计收益、单笔平均收益和等待交易数。
- 账户累计收益继续复用 `build_account_curve` 的每日等权、跨日复利口径。
- 一字板、停牌、缺价和不可买记录不进入有效交易及账户曲线。

## 弹窗与导出

- “历史模拟买入”和“收益率”弹窗保持不变。
- Excel 当前日模拟买入导出保持不变。

## 测试

- 主页面构建源码不再包含分时 Figure/Canvas 和分时区域标题。
- 主表使用完整页面宽度布局。
- 摘要渲染同时读取当前日流水和全部历史流水，并调用 `build_account_curve`。
- 现有弹窗、Excel、流水与收益计算测试继续通过。
